## 📌 Описание проекта
Проект представляет собой клиент-серверное консольное приложение на языке C, реализующее сетевую игру «Угадай число» по протоколу TCP.

* **Сервер:** Загадывает случайное целое число в диапазоне от 1 до 100, принимает подключения от клиентов, обрабатывает попытки и возвращает подсказки (`Higher`, `Lower`, `Correct!`). Сервер ведет подробный лог событий в консоли с указанием IP-адреса клиента.
* **Клиент:** Подключается к серверу по указанному IP-адресу и порту, принимает догадки от пользователя через стандартный ввод и отправляет их серверу до тех пор, пока число не будет угадано.

---

## ⚙️ Особенности реализации
1. **Протокол:** Использован надежный потоковый протокол TCP (`SOCK_STREAM`, семейство `AF_INET`).
2. **Сетевой порядок байтов:** Для передачи целочисленных значений между клиентом и сервером используются функции `htonl()` и `ntohl()`, что исключает проблемы несовместимости архитектур процессоров (Endianness).
3. **Формат логирования на сервере:** Все события фиксируются в формате:
   `<адрес клиента>:<сообщение>`

---

## 🛠️ Сборка проекта

Для компиляции потребуется компилятор `gcc` (среда Linux / WSL):

```bash
# Компиляция сервера
gcc server.c -o server

# Компиляция клиента
gcc client.c -o client
```

# 🚀 Запуск и использование

1. Запуск сервера

Сервер принимает в качестве аргумента командной строки номер порта, который будет прослушиваться:

./server 8080

2. Запуск клиента

В отдельном окне терминала запустите клиента, передав ему IP-адрес сервера и номер порта:

./client 127.0.0.1 8080
